# Parity notes: what the module does, and how the Go port matches it

Source of truth: `null-context` `main.tf`, `variables.tf`, `outputs.tf`, `descriptors.tf`.
Executable spec: `testdata/vectors.json` (generated by `tools/vectors/gen.py` from the real module).

## Evaluation order (internal/label/label.go `Compute`)

1. **local.input** - variables win over `var.context` (null = not set), except merged fields:
   `attributes` (concat, distinct, drop empty), `tags`, `additional_tag_map`, `descriptor_formats` (var wins per key).
2. `labels_as_tags`: if the parent's value is null or contains `"unset"`, use this call's value (default `["default"]`);
   otherwise the parent's value is kept and later calls cannot change it. Either way it is sorted and de-duplicated (set conversion).
3. Normalize each label: `replace(value, regex, "")` then case. Regex default `/[^-a-zA-Z0-9]/`; `""` falls back to the default (`coalesce`).
4. `label_order`: null or `[]` -> `[namespace, environment, stage, name, attributes]` (`coalescelist`). Unknown label -> error.
5. `id_full` = non-empty labels joined by the delimiter. `id` = `id_full` unless `id_length_limit != 0` and `id_full` is longer:
   `substr(trimsuffix(substr(id_full,0,limit-(5+len(delim))), delim) + delim + hash, 0, limit)`,
   where `hash = replace(case(md5(id_full) + "qrstuvwxyz"), regex, "")`. If `limit-(5+len(delim)) <= 0` the prefix is empty.
6. Tags: generated from `labels_as_tags` (`name` tag = the final `id`, `attributes` = joined string, empty values skipped,
   key case `title` by default), then `merge(generated, input.tags)` - **explicit tags win over generated ones**.
7. `tags_as_list_of_maps`: keys sorted, each `merge({key,value}, additional_tag_map)` (additional keys may override `key`/`value`).
8. `descriptors`: `format(fmt, labels...)`; argument count must equal verb count.
9. `dns_name`: 11 sequential literal replacements of `${namespace}`, `${tenant}`, `${project}`, `${region}`, `${environment}`,
   `${name}`, `${stage}`, `${id}`, `${attributes}`, `${domain_name}`, `${region}` (again). Order matters when a value itself contains a placeholder.

## Outputs and `enabled = false`

Blanked when disabled: `id`, `id_full`, `dns_name`, `namespace`, `tenant`, `environment`, `name`, `stage`, `delimiter`,
`attributes` (`[]`), `tags` (`{}`), `dns_name_format`, `domain_name`.
Not blanked: `enabled`, `additional_tag_map`, `label_order`, `regex_replace_chars`, `id_length_limit`,
`tags_as_list_of_maps`, `descriptors`, `normalized_context`, `legacy`, `self`.

## Quirks found by the vectors (all reproduced deliberately)

| Quirk | Consequence |
|---|---|
| `normalized_context` omits `project` and `region`; `self` keeps them | Chaining via `normalized_context` loses them. If a child's `label_order` includes them, the child's ID changes. Prefer `self`. |
| `normalized_context.tags` holds the parent's generated tags (incl. `Name` = parent's id) | A child chained via `normalized_context` keeps the **parent's** `Name` tag because input tags beat generated ones. Via `self` the child's `Name` is correct. |
| `legacy` has no `domain_name` / `dns_name_format`; `label_order` is a sorted set without project/region | Only for Cloud Posse modules; passing it to null-context fails (`Unsupported attribute`). |
| `labels_as_tags` first-set-wins; contains `"unset"` anywhere = unset | Implemented exactly; `lat_ctx_unset_among` covers it. |
| `title()` is Go `strings.Title` (word boundary = any non letter/digit/underscore) | Same function is used. |
| `regex_replace_chars` wrapped in `/.../` is RE2; `"/"` or `"//"`-like edge cases follow Terraform's `len > 1` rule | `regex_double_slash`, `regex_single_slash_literal` vectors. |
| `id_length_limit` is only validated on the variable, `label_*_case` on both context and variable | Validated separately in `Compute`. |
| Direct `var.context.dns_name_format` access | A context without `domain_name`/`dns_name_format` fails in the module; the port is lenient (treats missing as null). A superset, not a regression. |

## Unicode and `format()` semantics (found by differential fuzzing)

The hand-written vectors passed while random Unicode inputs exposed four differences. All are now reproduced and guarded by vectors
(`nfc_*`, `limit_grapheme_*`, `desc_odd_*`, `desc_fmt_*`) and by mutations in `tools/mutation/mutate.py`.

| Behaviour in Terraform | Port |
|---|---|
| **Every string is NFC-normalized** (cty), including every string function result and object/map keys. `a` + U+0308 becomes `ä`, so the default regex strips it. | `nfc()` on all inputs and after every string step (`normalizeContext`, `tfReplace`, case functions, joins, templates, `format`). |
| `length()`/`substr()` count **extended grapheme clusters** (an emoji family or `a` + two combining marks is 1). Affects `id_length_limit`, the hash cut and the delimiter length. | `tfStrlen`/`tfSubstr` via `go-textseg/v15`. |
| `format("%q", s)` is **JSON string quoting** (`encoding/json`, HTML escaping on): escapes `"` `\` control chars `<` `>` `&` U+2028/2029; keeps ZWJ, NBSP, private-use etc. raw. Not `strconv.Quote`. | `jsonQuote`. |
| `format` width and precision count grapheme clusters; precision truncates **before** `%q` quotes; width pads the quoted text; `%08s` zero-pads, `%-08s` zero-fills on the **right**; `+`, space and `#` are ignored for strings; `%.s` means no precision; `%*s` and other verbs are errors; verb/argument counts must match. | `tfFormat`. |

Method: `tools/vectors/fuzz.py` generates random but valid inputs (words, messy punctuation, accented, decomposed, emoji, ZWJ, control and format
characters, odd regexes and delimiters, random `label_order`/limits/descriptor formats/dns formats, chained contexts via `self` and
`normalized_context`), runs them through the reference module in one `terraform apply`, and the Go core and built provider are compared on all 23 outputs.

## Worked example: `project` in `label_order`, `region` not

Parent: `namespace=acme, project="Project 1", environment=dev, stage=sandbox-01, name=baz, attributes=[1,2]`,
`label_order=[namespace, project, environment, stage, name, attributes]`. Child adds `name=child, attributes=[x]`.

| Child chained via | Child `id` | Child `Name` tag |
|---|---|---|
| `self` | `acme-project1-dev-sandbox-01-child-1-2-x` (correct) | child's id |
| `normalized_context` | `acme-dev-sandbox-01-child-1-2-x` (**`project` lost**) | the **parent's** id |

Vectors: `proj_order`, `chain_proj_order_*`, `chain_projorder_child_*`, `chain_projorder_leaf_*`. The Go core and the provider reproduce both rows
exactly, so migrating does not change IDs; but any module that chains via `normalized_context` has this latent bug today.
Find them with `grep -rn normalized_context` over your modules before migrating, and decide per module whether to switch to `self`
(changes the ID: needs a plan review) or keep the current behaviour.

## Not covered (known gaps)

- Unicode table drift: the port uses the Unicode tables of the Go toolchain it is built with; Terraform uses its own. Differences are possible only for code points added in the newest Unicode versions.
- `format()` with non-string arguments (descriptors only ever format strings) and verbs other than `%s %v %q`.
- Error message text is not compared, only that an error occurs (`vectors.json` records Terraform's text for reference).
- Real-stack plan diffs (phase 4 was out of scope for now).

## Adding coverage

Edit `tools/vectors/cases.py`, run `make vectors`, then `make test provider-parity mutation`.
A surviving mutation means a behaviour is unguarded: add a vector that distinguishes it.
